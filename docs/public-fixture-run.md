# Public fixture check

Run date: October 21, 2026.

This record covers the small deterministic public demonstration, not the original LlamaIndex/BGE/Mistral evaluation. The historical metrics in the other studies have not been reproduced on this fixture.

## Commands run

From the repository root:

```bash
python3 scripts/create_public_fixture.py
python3 -m unittest discover -s tests -v
python3 scripts/offline_demo.py
```

Tested package versions are in [requirements-demo.txt](../requirements-demo.txt). The input is generated by this repository; no supplied project documents or hosted-model credentials are required.

## Observed result

- Three unit tests passed.
- Both searchable certificate questions returned the expected field from the expected page.
- The generic lot-number question requested clarification between the two certificates.
- The third, image-only page was detected. Its OCR check was skipped because the system Tesseract executable was unavailable.

See [the exact check record](../data/public-fixtures/offline-checks.json) and [the checked questions](../data/public-fixtures/answer-key.json). Skipped OCR behavior is not a passed OCR evaluation. Elapsed time in that JSON is for this tiny deterministic reference run and is not comparable to the historical model timings.
