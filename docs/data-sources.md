# Data sources and public-edition boundary

This project grew out of Pranish Pakwan's Pfizer externship with Extern in 2026. The original guided work used supplied learning resources, starter material, and pharmaceutical documents. The findings describe the author's comparisons and evaluation, not a deployed Pfizer service or Pfizer-endorsed benchmark.

## Included here

- Sanitized notebook adaptations and the author's readable experiment summaries.
- A new, fictional PDF generated by `scripts/create_public_fixture.py`. Every document is marked as fictional; identifiers, products, names, and dates are invented.
- A small public answer key and the actual offline reference-check record.

The notebook files preserve educational adaptation context. They are not claimed as independently invented frameworks or production engineering. Existing third-party package and model terms continue to apply. This repository does not add a blanket license over supplied learning material or third-party components.

## Excluded

The original supplied PDFs, report PDFs, slide templates and decks, extracted source text and images, saved historical notebook outputs, and private Git history are not included. Notebook 07 is omitted because its source embeds document-specific extracted values. Earlier numbered notebooks remain historical studies and may require unavailable original inputs.

## Which results belong to which data

The reported five-question, ten-page, twenty-eight-chunk RAG evaluation belongs to the original private input. Its answer key, raw field values, and source pages are not published here. Those percentages are historical observations, not new measurements on the fictional fixture.

The public fixture has three pages. Its check record is a separate deterministic extraction/retrieval demonstration. It does not use the original embedding/Mistral pipeline. An unavailable OCR executable is recorded as a skip; it is not counted as verified OCR behavior.

## Dates

Original project learning took place June through August 2026. Original Git records span July 29 through September 2, 2026. The clean public edition was prepared on October 21, 2026 with its own real release-date commits. Original private history is preserved separately and has not been backdated or imported.
