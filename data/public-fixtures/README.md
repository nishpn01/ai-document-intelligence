# Public synthetic fixture

`synthetic-quality-documents.pdf` is generated by this project for demonstration. It contains two searchable, fictional quality certificates (CERT-FIC-101 / LOT-FIC-ALPHA and CERT-FIC-202 / LOT-FIC-BRAVO) and a third image-only scanned inspection page. All names, identifiers, products, and dates are invented; the pages are visibly marked as fictional samples. No real company or person is represented.

Regenerate it with `python scripts/create_public_fixture.py` from the candidate root. `answer-key.json` lists the small checked examples, including the ambiguous generic lot query. Sharing terms: original synthetic material created for this demo; no third-party document content is included.
